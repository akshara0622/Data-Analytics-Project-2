# Data Analytics Project 2 - Exploratory Data Analysis

## Objective
Perform exploratory data analysis to understand patterns, trends, and distributions in the dataset.

## Tasks Performed
- Loaded the dataset
- Calculated descriptive statistics
- Checked missing values
- Identified duplicate records
- Analyzed trends and outliers
- Summarized findings

## Tools Used
- Python
- Pandas
- Matplotlib
- VS Code
## Summary
The dataset was successfully analyzed using Exploratory Data Analysis (EDA) techniques. Basic descriptive statistics such as mean, median, minimum, and maximum values were calculated. The dataset contains 1,200 records and 14 columns. A total of 309 missing values were identified in the CouponCode column, while no duplicate rows were found. Outlier analysis detected 8 potential outliers in the TotalPrice column. A histogram was generated to visualize the distribution of TotalPrice values, providing insights into the overall data pattern.
